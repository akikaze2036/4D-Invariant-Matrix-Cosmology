## 1. 宇宙のキャンバス（4次元不変母体空間）

宇宙の真の舞台は、膨らんだり縮んだり、グニャグニャと歪んだりしない、静止した完全平坦な「4次元の土台（母体空間）」です。

- **過去から未来までが詰まった世界**：時間軸を含む4次元の母体には、過去も未来もすべてが同時に詰まっており、エネルギーの総量も不変です。ここには、私たちが普段感じるような「流れる時間」はありません。
- **宇宙を生み出す素地**：この母体から無数の宇宙が生まれ、すぐに発散して消えたり、スカスカになったり、私たちがいる宇宙になったりと、さまざまな宇宙が生まれるベースとなっています。

## 2. 万物の正体は「エネルギーの濃淡と波の重なり」

この世界に「固い物質」や「見えない力」というバラバラな独立した実体はありません。

すべては、静止したキャンバスの上にある **「エネルギーの濃淡（高い・低い）」** です。
エネルギーの山が高くなったり低くなったりしながら複雑な波のパターンとして広がり、その **波の重なり合いと結合（波紋の相互作用）** のすべてが万物の現象を生み出してきます。

## 3. 時間の正体：時間は流れていない（錯覚のメカニズム）

この理論の最大の核心は、「時間は流れておらず、進んでもいない」という点にあります。母体の上で過去も未来もすでに存在している中で、私たちが感じている「いま何時」「時間が過ぎる」という感覚の正体は、次のように定義されます。

- **座標時間（時間軸の目盛り）**：4次元空間の時間軸上の不変の目盛り。
- **空間時間（見かけの時刻）**：人間社会の根幹にある「時刻」や「時間の流れ」そのものです。ビッグバンから続いている波紋の広がりは、空間だけでなく**時間軸方向**にも広がっており、この広がりが「空間時間」を生んでいます。
- **時間の流れの正体**：時間軸方向の広がりが「昼と夜」や「四季」などとして現れ、それを人間が「時間の流れ」として受け取りました。
- **時間の遅れと変化**：宇宙の波紋が広がるにつれて、**波の山と山の間隔はどんどん広がっています**（例：100年前の山の間隔が「4」だったとすれば、現在は「5」に広がっている）。また、重力や速度が変化すると波に干渉が起きるため、その場所における**時間の流れのスピードも変化**します。

## 4. 宇宙のルール：共通のルールとローカルルール

方程式が理解できなくていい。  
シンプルだ。短い。これだけで万物を表せるのか？そんな感覚が大切です。  

$$\frac{1}{c^2} \frac{\partial^2 u}{\partial \tau^2} + \frac{1}{\alpha_0} \frac{\partial u}{\partial \tau} = K(u) \nabla^2 u - \beta(\nabla u) \cdot u^2$$

**（※「Ver 1.1」で追加された基本方程式）**

- $u(\boldsymbol{x}, \tau)$：母体空間におけるエネルギー密度（濃淡）
- $\tau$：母体空間における絶対座標時間（伝播パラメーター）
- $\alpha_0$：エントロピー均一化の散逸係数（基本緩和時間）
- $\frac{1}{c^2} \frac{\partial^2 u}{\partial \tau^2}$：波動伝播のエネルギーとなる慣性項（伝播速度の絶対上限は光速 $c$）
- $\frac{1}{\alpha_0} \frac{\partial u}{\partial \tau}$：エントロピー均一化の散逸項
- $K(u)$：万物の復元係数（エネルギー密度 $u$ に依存する拡散・復元力）
- $\beta(\nabla u)$：万物の高密度自己相互作用結合定数（エネルギー勾配 $\nabla u$ に依存する非線形自己抵抗・粘性）
- $\nabla^2$：4次元ラプラシアン演算子（ $\frac{\partial^2}{\partial (x^1)^2} + \frac{\partial^2}{\partial (x^2)^2} + \frac{\partial^2}{\partial (x^3)^2} + \frac{\partial^2}{\partial (x^4)^2}$ ）

万物のふるまいは、方程式の「左辺」と「右辺」のように役割分担されています。

- **左辺（母体の共通ルール）**：どこの宇宙でも通用する、母体上の絶対的なエネルギー量。
- **右辺（ローカルルール）**：素粒子、人間、月、象など、その対象ごとの特徴に合わせて**その場で自律的に決まるルール**。

**大切なのは、「母体のルール」と「ローカルルール」が同じであるということです。**  
**母体も万物も、同じ法則で成り立っているのです。**

このローカルルールを形作るキーパーソンが、次の2つです。

1. **復元力 $K(u)$**：慣性によって、波紋を広げようとする力。
2. **自己抵抗 $\beta(\nabla u)$**：波紋が広がるときにかかる抵抗や粘り。
   - *【たとえ話】* まるで**マグマが広がろうとする力と、その粘り気**のような関係です。この「広がる力」と「粘り」のバランスが、その場所の動きをすべて決めます。

## 5. 素粒子の誕生と、宇宙の循環（リサイクル）

- **素粒子の正体（位相的ソリトン）**：
  ビッグバンのとき、エネルギー密度が限界を超えてエントロピーを均一化しようとする働きが爆発的に起きました。その際、適度な粘り（自己抵抗）が効いて急な斜面（急勾配）が生まれ、飛行機の翼にできる空気の渦（泡）のように、波が自分で自分を巻き込んでほどけなくなった「泡」ができました。これが素粒子（電子やクォークなど）の正体です。
- **宇宙の寿命とマルチバース循環**：
  我々の宇宙も波紋である以上、いつかは寿命を迎えます。しかし、エネルギーが消えてなくなるわけではありません。寿命を迎えた宇宙は「微力な波紋」として残り続け、それらが波の結合や干渉によって再び集まることで、新しい宇宙の種へとつながっていく（持続可能な宇宙のリサイクル）仕組みになっています。
