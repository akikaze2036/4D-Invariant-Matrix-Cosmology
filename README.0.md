## 0. はじめに：なぜ「前提」が必要なのか？

現代物理学の多くの理論は、空間と時間を切り離し、異なる次元・異なる単位として扱ってきました。しかし本理論（4次元不変母体宇宙論）では、4次元母体空間の全域で同一の物理法則が貫かれていると考えます。

もしこの前提や次元の整合性を共有しないまま方程式を眺めると、数式の意味や単位の次元が狂って見えてしまいます。本章では、私たちが無意識に囚われている「時間と空間の錯覚」を解きほぐし、基本方程式が成り立つ土台を整えます。

## 1. 母体（母体空間）とは何か？

本理論は、永遠に静止した平坦な4次元の不変空間（母体空間）を世界の基本土台（キャンバス）としています。

* **過去から未来までの全容**：母体の上には、過去から未来までがすべて詰まっており、宇宙全体のエネルギー総量は常に保たれています。


* **宇宙の循環（リサイクル）**：母体上では無数の宇宙の創造と衰退が繰り返されています。衰退した宇宙のエネルギーは失われず、他の衰退宇宙と結合・干渉し、新たな宇宙を創生するエネルギー源となります。

## 2. 時間の正体：なぜ時間は特別扱いされたのか？

現代物理学では時間が「空間とは全く別の特別なもの」として扱われていますが、それは人間が生存する中で植え付けられた「錯覚」と「歴史的背景」によるものです。

### 2.1 時間が特別扱いされてきた4つの理由

1. **生存の直感（空間は戻れる、時間は戻らない）**：前後左右には自由に移動できるが、時間は過去から未来へ一方向にしか進めないという圧倒的な身体感覚。


2. **道具と単位の違い**：空間を測る「定規（メートル / $m$）」と、時間を測る「時計（秒 / $s$）」を別々に作り、計算上も別枠にするのが便利だったから。


3. **ニュートンの絶対空間・絶対時間**：17世紀に「静止した巨大なステージ（空間）」と「等しく進む時計（時間）」を完全に切り分けたアプローチが成功しすぎたため。


4. **不可逆性**：時間が一方向であるため、自由に移動できる空間とは異質に感じられたこと。



### 2.2 空間の長さと時間の長さは等価である

本理論では、空間の長さと時間の長さは等価（ $L = T$ ）であると考えます。

* **時間は流れていない**：11時から12時までの1時間も、3時から4時までの1時間も、時間軸上の「A点とB点の間隔（長さ）」を測っているに過ぎません。


* **「今（now）」の正体**：宇宙誕生の瞬間に生まれた波紋は、空間だけでなく**時間軸方向**にも無限に広がっています。その波紋の最前線の到達点が、私たちが「現在・今」と呼んでいるものの正体です。時間が流れているのではなく、**「時間軸を伝わる波紋の広がり」を「時間の流れ」と錯覚している**のです。

## 3. 思考実験：仕事（エネルギー）と質量の次元的等価性

ここで、物理学の基本的な方程式を用いて次元のつながりを確認してみましょう。

* ニュートンの運動方程式： $F = ma$ （力 ＝ 質量 $\times$ 加速度）


* 仕事（エネルギー）の定義： $J = N \cdot m$ （ジュール ＝ ニュートン $\times$ メートル）



### ステップの展開

1. **$N \cdot m$ とは何か？**：力を加えて物体を動かしたときのエネルギー（仕事）の単位。


2. **ニュートン（ $N$ ）の分解**： $F = ma$ より、質量（ $\text{kg} \to M$ ）$\times$ 加速度（ $\text{m/s}^2 \to L T^{-2}$ ）。次元は $[M L T^{-2}]$。


3. **距離（ $m$ ）の乗算**：さらに距離（ $L$ ）を掛けると、仕事（エネルギー）の次元は **$[M L^2 T^{-2}]$**（ $\text{kg} \cdot \text{m}^2 / \text{s}^2$ ）となります。



### 本理論による拡張

現代物理学ではここで止まりますが、本理論の前提である **$L = T$（空間の長さと時間の長さが等価）** をこの次元 $[M L^2 T^{-2}]$ に適用すると、次のように変形できます。

$$\text{次元：} [M L^2 (L)^{-2}] = [M]$$

時間と空間の次元が等価であるとみなすことで、**次元の上では「仕事（エネルギー）」と「質量」が本質的に同一（ $[M]$ ）であること**が導かれます。これを相互変換する具体的なダイナミクスを記述するのが、本編の基礎波動方程式です。

## 4. 基本仮定のまとめ

本理論の基礎波動方程式へ進むにあたり、以下の前提を共有します。

* **母体空間**：4次元の完全平坦な空間。私たちが感じる「空間の歪み」は、すべてエネルギー密度の濃淡に過ぎない。


* **宇宙の循環**：宇宙の創生と衰退はループし、衰退した宇宙のエネルギーは次の宇宙の種となる。


* **光速の限界**：エネルギー密度が無限大になることはなく、限界を超えるとエントロピー均一化の波紋として全方位へ拡散する。その限界点が「光速 $c$」である。


* **時間**：時間軸上の目盛り値である「座標時間（ $\tau$ ）」と波紋の山と山の間隔の伸びとして現れる見かけの「空間時間」が存在する。
